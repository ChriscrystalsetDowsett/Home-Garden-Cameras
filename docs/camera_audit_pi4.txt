SUMMARY — WHAT CHANGES ARE NEEDED AFTER THE USB CAMERA SWAP
================================================================================

1. CAMERA MODULE 3 CONFIRMED ATTACHED: YES
   IMX708 detected on CSI bus at /base/soc/i2c0mux/i2c@1/imx708@1a
   (rpicam-hello confirms; vcgencmd output is a legacy tool and can be ignored)

2. SERVICE NAME AND START COMMAND:
   Service:   garden-monitor.service
   Start:     python3 run.py
              (invoked via /home/chris/garden-monitor/scripts/start.sh --fg)
   User:      chris
   WorkDir:   /home/chris/garden-monitor

3. LIBCAMERA-SPECIFIC ITEMS TO ADDRESS AFTER USB SWAP:
   a) config/settings.yaml — ADD:  backend: "v4l2"  under the camera: block
      This is the ONLY required change to the app to switch backends.
   b) V4L2_DEVICE="/dev/video0" (camera.py:15) — verify the USB camera
      appears on /dev/video0 after plugging in. If it lands elsewhere
      (e.g. /dev/video2 because unicam occupies video0), either:
        • Disable the CSI overlay in /boot/firmware/config.txt, OR
        • Change V4L2_DEVICE in camera.py to the correct node.
   c) picamera2 pip package and python3-libcamera system package can be
      left installed (they are harmless) — no need to uninstall.
   d) autofocus (AfMode/AfRange) will silently no-op via the existing guard
      in timelapse.py — no code change needed.

4. CONFIG VALUES TO CHANGE IN settings.yaml:
   REQUIRED:
     camera.backend: "v4l2"           (add this key — currently missing/defaults to picamera2)
   OPTIONAL / COSMETIC:
     camera.name: "Pi 4 USB"          (or whatever identifies this feed in the dashboard)
     camera.default_resolution: ...   (USB webcam may not support 1920x1080; check with v4l2-ctl)
     camera.hflip / vflip:            (adjust for new physical camera orientation)

5. GIT REPO URL:
